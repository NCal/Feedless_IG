# Feedless IG 🧘

A Chrome extension that replaces your Instagram feed with an inspirational quote —
while keeping the rest of the site fully usable.

- ✅ Replaces the home feed with an inspirational quote
- ✅ Keeps DMs, Stories, notifications, and profiles fully functional
- ✅ No data collected, no tracking, nothing leaves your browser
- ✅ Works automatically — no configuration needed

## Installation (from source)

1. Download or clone this repository
2. Open Chrome and navigate to `chrome://extensions`
3. Enable **Developer mode** (toggle in the top-right corner)
4. Click **Load unpacked** and select the project folder
5. Visit instagram.com — your feed is now a quote


## Permissions

| Permission | Reason |
|---|---|
| Host access to `instagram.com` | Needed to replace the feed on Instagram pages |

That's it — no broad web access, no background scripts phoning home.

## Privacy

Feedless IG collects nothing. No analytics, no accounts, no remote servers.
All processing happens locally in your browser.

## FAQ

**Does this block Instagram entirely?**
No — only the home feed is replaced. You can still message, post, and browse profiles.

**Will it break when Instagram updates?**
Possibly — Instagram changes its markup frequently.

**Can I disable it temporarily?**
Yes — pin the extension and toggle it off from the toolbar whenever you want the feed back.
